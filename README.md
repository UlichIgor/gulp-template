# Gulp Template — навчальний курс для початківців

Цей репозиторій — практичний стартовий шаблон і покроковий курс українською мовою. Ви навчитеся налаштовувати середовище, запускати Gulp, автоматизувати обробку HTML, SCSS, JavaScript, зображень і шрифтів, створювати production-збірку та публікувати сайт.

> **Стан проєкту:** production-збірка перевірена GitHub Actions на Node.js 20. Остання перевірка: [Gulp build](https://github.com/UlichIgor/gulp-template/actions).

## Почати за 5 хвилин

1. Встановіть [Node.js LTS](https://nodejs.org/) і Git.
2. Клонуйте репозиторій:
   `git clone https://github.com/UlichIgor/gulp-template.git`
3. Перейдіть до папки:
   `cd gulp-template`
4. Встановіть залежності:
   `npm ci`
5. Запустіть режим розробки:
   `npm run dev`

Gulp збере файли у папку `assets`, запустить BrowserSync і відкриє сторінку в браузері. Зупинити сервер можна клавішами `Ctrl + C`.

## Основні команди

| Команда | Що робить |
| --- | --- |
| `npm ci` | Встановлює залежності точно за lock-файлом |
| `npm run dev` | Збирає файли для розробки та запускає BrowserSync |
| `npm run prod` | Створює оптимізований сайт у `dist/` |
| `npm run clean` | Видаляє згенеровані папки `maps`, `assets` і `dist` |
| `npm run deploy` | Публікує вміст `dist/` через gh-pages |

Після змін у вихідних файлах перевіряйте сайт командою `npm run dev`. Перед публікацією обов'язково виконайте `npm run prod` і перевірте папку `dist/`.

## Як влаштований проєкт

```text
src/
  html/       HTML-фрагменти (header, content, footer)
  images/     зображення та SVG-іконки
  fonts/      вихідні TTF-шрифти
  js/         JavaScript
  resources/  favicon та інші статичні файли
  scss/       SCSS-стилі
  index.html  головний HTML-шаблон

gulp/
  dev/        задачі для локальної розробки
  prod/       задачі для production-збірки

assets/       результат локальної збірки
dist/         готовий оптимізований сайт
gulpfile.babel.js
paths.js      шляхи до файлів
package.json  команди та залежності
COURSE.md     повний навчальний курс
```

## Як працює збірка

**Розробка:** очищення `assets` → паралельна обробка шрифтів, зображень і ресурсів → створення SVG-спрайту → компіляція стилів, скриптів і HTML → запуск BrowserSync.

**Production:** очищення `dist` → обробка ресурсів → SVG-спрайт → оптимізовані CSS, JavaScript та HTML. BrowserSync у production не запускається, тому команда завершується після створення файлів.

## Практичне завдання

1. Змініть заголовок у `src/html/content.html`.
2. Додайте власне правило CSS у `src/scss/page/content.scss`.
3. Додайте невеликий JavaScript у `src/js/main.js`.
4. Запустіть `npm run dev` і перевірте результат.
5. Запустіть `npm run prod` та переконайтеся, що створився `dist/index.html`.

## Перевірка якості
